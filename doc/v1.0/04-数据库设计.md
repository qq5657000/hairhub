# HairHub V1.0 数据库设计

> Version: 1.1.0  
> Last Update: 2026-07-09

---

# 一、数据库设计目标

HairHub 是一个：

> 以 AI 工具为入口，以发型内容为核心，以 SEO 获取流量，以微信生态完成商业转化的平台。

数据库设计围绕：

- AI 能力
- 发型资产
- 发色资产
- 内容资产
- SEO 增长
- 微信生态

进行设计。

数据库目标：

- 支持 V1 快速上线
- 支持 Dcat Admin 后台管理
- 支持 Laravel Eloquent ORM
- 支持未来多语言扩展
- 支持 AI 模型替换
- 支持内容规模增长
- 支持未来商业化扩展

---

# 二、数据库设计原则

## 2.1 简单优先

V1 阶段不进行过度设计。

优先保证：

- 开发效率
- 代码可维护
- 数据结构清晰

---

## 2.2 Laravel 友好

遵循 Laravel 默认规范：

- MySQL
- Eloquent ORM
- Migration
- Model

---

## 2.3 数据资产优先

HairHub 长期价值：

不是 AI 模型本身。

而是：

```
大量发型数据

+

发色数据

+

文章内容

+

视频内容

+

用户生成数据
```

因此数据库重点围绕内容资产设计。

---

# 三、数据库基础规范

## 3.1 数据库

```
MySQL 8+
```

---

## 3.2 表命名规范

采用 Laravel 默认规范：

```
小写

下划线

复数形式
```

例如：

```
hairstyles

hair_colors

articles

media_files
```

---

## 3.3 主键规范

所有业务表：

```sql
id bigint unsigned
```

---

## 3.4 时间字段

默认包含：

```sql
created_at

updated_at
```

---

## 3.5 状态字段

统一：

```sql
status tinyint
```

规则：

```
0 禁用

1 正常
```
