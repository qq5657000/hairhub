# HairHub V1.0 系统架构

> Version: 1.0.0  
> Last Update: 2026-07-08

---

# 一、架构目标

HairHub V1.0 的架构目标：

> 在保证快速开发和快速上线的前提下，建立一个稳定、清晰、可扩展的 Laravel 应用架构。

系统设计不追求复杂化，而是在满足当前业务需求的基础上，为未来扩展预留空间。

核心目标：

- 保持代码结构简单
- 符合 Laravel 官方开发习惯
- 降低个人开发维护成本
- 支持未来业务增长
- 支持 AI 模型替换
- 支持前后端分离扩展

---

# 二、架构设计理念

HairHub 采用：

> **Laravel + Dcat Admin + Service Layer 分层架构**

整体设计遵循：

- 高内聚
- 低耦合
- API First
- Configuration First
- Future Ready

---

# 三、核心设计原则

## 1、高内聚（High Cohesion）

每个功能模块只负责自己的业务。

例如：

AI 模块负责：

- AI任务创建
- AI接口调用
- 任务状态管理
- 结果处理

发型中心负责：

- 发型分类
- 发型数据
- 发型展示

内容中心负责：

- 文章
- 视频
- 专题

不同模块之间保持职责清晰。

---

# 2、低耦合（Low Coupling）

业务代码不直接依赖第三方服务。

例如：

AI模型：

- HairFastGAN
- OpenAI
- ComfyUI
- Flux

统一通过 AI Service 调用。

未来更换模型时，只需要修改 AI 服务层，不影响业务代码。

---

# 3、Service Layer 分层

Controller 不负责复杂业务逻辑。

统一流程：

```
Request

↓

Controller

↓

Service

↓

Repository

↓

Model

↓

Database
```

职责：

## Controller

负责：

- 接收请求
- 参数验证
- 调用 Service
- 返回结果

不处理业务逻辑。

---

## Service

负责：

- 核心业务逻辑
- 多个数据操作组合
- 第三方服务调用

例如：

```
AiService

createTask()

queryTask()

generateResult()
```

---

## Repository

负责：

- 数据查询
- 数据保存
- 数据筛选

避免业务代码直接操作数据库。

---

## Model

负责：

- 数据结构
- ORM关系
- 数据访问基础能力

# 五、技术架构组成

## 1、前端层

负责用户展示和交互。

包括：

- Web网站
- H5
- 微信小程序
- 未来App

所有前端统一通过 API 获取数据。

---

## 2、API层

Laravel API 是系统核心入口。

负责：

- 用户请求处理
- 数据返回
- 权限验证（未来）
- API版本管理

接口规范：

```
/api/v1/*
```

例如：

```
GET

/api/v1/hairstyles

/api/v1/articles


POST

/api/v1/ai/tasks
```

---

## 3、业务服务层

Service Layer 是系统核心。

负责：

- 发型业务
- 发色业务
- 内容业务
- AI业务
- SEO业务

所有业务逻辑集中管理。

---

## 4、数据层

采用：

- MySQL
- Laravel Eloquent ORM

负责：

- 数据持久化
- 数据关系管理

---

# 六、Dcat Admin 后台架构

HairHub 使用 Dcat Admin 作为后台管理系统。

Dcat Admin 负责：

- 内容管理
- 发型管理
- 发色管理
- AI配置
- SEO管理
- 系统配置

目录：

```
app/Admin

├── Controllers

├── Forms

├── Metrics

├── Actions

├── Extensions

└── routes.php
```

---

Dcat Admin 与前台 API 分离：

```
Dcat Admin

负责管理数据


API

负责提供数据


前端

负责展示数据
```

---

# 七、AI 服务架构

HairHub 不负责 AI 模型推理。

AI能力通过 API 接入。

架构：

```
API

↓

AiService

↓

AI Provider

↓

HairFastGAN API
```

---

V1.0 当前：

```
HairFastGAN
```

未来支持：

```
OpenAI

ComfyUI

Flux

其它AI模型
```

---

AI Service 负责：

- 创建任务
- 调用接口
- 查询状态
- 保存结果
- 异常处理

---

# 八、Media资源架构

HairHub 是内容型平台。

图片和视频是核心资产。

因此设计 Media Service。

负责：

- 图片上传
- 图片管理
- 视频管理
- 文件地址管理
- 存储策略

支持未来扩展：

当前：

```
本地Storage
```

未来：

```
OSS

Cloudflare R2

CDN
```

业务代码无需修改。

---

# 九、SEO架构

SEO 是 HairHub 的核心增长能力。

SEO模块负责：

- 页面Title
- Description
- Keywords
- URL Slug
- Sitemap
- Robots
- Canonical
- JSON-LD

SEO数据由后台配置。

避免写死在代码中。

# 十一、模块通信原则

模块之间：

禁止：

- 直接操作其他模块数据库
- Controller调用Controller
- Service之间循环依赖


推荐：

```
Service

调用

Repository

或者

公共Service
```

# 十二、当前版本不引入的架构

V1.0 不采用：

- 微服务
- 分布式系统
- 消息队列集群
- 独立AI服务器集群
- 复杂权限系统

原因：

当前阶段优先快速上线和验证业务。
