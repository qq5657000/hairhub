# 一、生态定位

HairHub V1.0 的生态定位：

> 网站负责沉淀内容资产和获取 SEO 流量，短视频平台负责获取公域流量，微信生态负责用户沉淀、复访和商品转化。

HairHub 不在 V1.0 自建商城，不做支付、订单和库存系统。

当前转化生态包括：

```text
HairHub 网站

微信公众号 / 服务号

微信小程序

微信小店

视频号

抖音

快手

小红书

B站
```

---

# 二、整体转化路径

HairHub V1.0 的整体增长路径：

```text
HairHub文章 / 发型图库 / 发色视频

↓

提炼短视频脚本

↓

发布到视频号、抖音、快手、小红书、B站

↓

引导用户进入微信小程序

↓

体验 AI 换发型 / AI 换发色

↓

进入微信小店

↓

完成商品转化
```

# 六、视频内容来源

短视频内容灵感主要来自 HairHub 的文章内容。

例如文章：

```text
圆脸男生适合什么发型？

第一次染发选什么颜色最安全？

男生头发容易塌怎么办？

儿童运动时如何扎头发？

女生头发毛躁怎么办？
```

可以拆成短视频：

```text
3款适合圆脸男生的发型

第一次染发千万别选这3种颜色

男生头发塌，试试这4个方法

孩子运动扎头发，这样最清爽

女生头发毛躁，先看这几个原因
```

# 八、视频内容回填 HairHub


# 九、视频字幕与文字说明



# 十一、微信公众号文章同步

## 11.1 目标

后台文章编辑完成后，可以同步到微信公众号。

同步目的：

```text
减少重复排版

提高内容分发效率

保持网站与公众号内容一致

公众号反向引流网站和小程序
```

---

## 11.2 内容来源

文章表：

```text
articles
```

字段：

```text
content

wechat_content

wechat_cover

wechat_excerpt
```

其中：

```text
content = 网站正文

wechat_content = 公众号正文

wechat_cover = 公众号封面

wechat_excerpt = 公众号摘要
```

---

## 11.3 同步入口

文章编辑页提供：

```text
同步微信公众号
```

按钮。

同步记录在：

```text
wechat_articles
```

---

## 11.4 同步流程

```text
后台编辑文章

↓

填写网站正文

↓

复制或编辑公众号正文

↓

填写公众号封面和摘要

↓

点击同步微信公众号

↓

检查微信配置

↓

上传公众号正文图片

↓

上传封面图片

↓

创建微信草稿或发布

↓

保存同步记录

↓

更新文章同步状态
```

# 十四、Access Token 策略

Access Token 不应每次请求都重新获取。

应缓存到：

```text
Cache / Redis
```

缓存 key 示例：

```text
hairhub:wechat:access_token
```

如果微信返回 token 失效，应：

```text
清除缓存

重新获取 token

重试一次
```

# 二十、平台引导注意事项

不同平台对外链、二维码、微信引流限制不同。

发布内容时应注意：

```text
避免违规硬广

避免过度引导站外

避免频繁出现敏感词

根据平台规则调整文案

优先使用品牌名搜索引导

评论区和私信谨慎使用
```

示例引导：

```text
可以搜索「AI换发型工具」体验同款效果。
```

```text
想试自己的照片，可以看主页入口。
```

# 二十二、安全要求

以下内容不得写死到代码：

```text
AppID

AppSecret

Access Token

接口 Token

EncodingAESKey
```

日志中不得记录：

```text
AppSecret

Access Token

用户隐私图片

完整敏感接口返回
```

后台同步微信公众号接口只能管理员使用。
