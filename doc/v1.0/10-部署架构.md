# HairHub V1.0 部署架构

> Version: 1.0.0
> Last Update: 2026-07-09
> Document Path: `docs/v1.0/10-部署架构.md`

---

# 一、部署目标

HairHub V1.0 的部署目标：

> 稳定、简单、可维护，优先保证网站、后台、API 和 AI 服务调用正常运行。

V1.0 不追求复杂分布式架构。

---

# 二、整体部署结构

```text
用户浏览器 / 微信浏览器 / 小程序
        ↓
      HTTPS
        ↓
    Nginx
        ↓
 Laravel 10 + Dcat Admin
        ↓
 MySQL / Redis / Storage
        ↓
HairFastGAN 独立 4090D AI服务器
```

---

# 三、服务器角色

## 3.1 Web 应用服务器

负责：

```text
Laravel API

Web/H5 页面

Dcat Admin 后台

图片上传

SEO页面

微信公众号接口调用
```

---

## 3.2 AI 服务器

当前为独立 4090D 显卡主机。

负责：

```text
HairFastGAN 模型推理

AI换发型

AI换发色或后续AI能力
```

HairHub 不在 Web 服务器上运行 AI 模型。

# 五、域名规划

建议：

```text
www.aihairhub.com        前台网站

api.aihairhub.com        API接口，可选

admin.aihairhub.com      后台，可选

static.aihairhub.com     静态资源/CDN，可选
```

V1.0 可以先使用同一域名不同路径：

```text
https://www.aihairhub.com

https://www.aihairhub.com/admin

https://www.aihairhub.com/api/v1
```

# 六、Nginx 配置目标

Nginx 负责：

```text
HTTPS

反向代理

静态资源访问

Laravel入口转发

上传文件访问控制

Gzip压缩
```

# 七、Laravel 环境配置

生产环境必须设置：

```text
APP_ENV=production

APP_DEBUG=false

APP_URL=https://www.aihairhub.com
```

敏感信息放入：

```text
.env
```

不要提交到 Git。

---

```text
发型数据

发色数据

文章内容

视频内容

AI任务

媒体资源

SEO信息

系统配置
```

生产环境要求：

```text
定期备份

限制远程访问

```

# 九、Redis

Redis 用于：

```text
缓存

队列

任务状态

频率限制
```

V1.0 如果功能较简单，可以先不强依赖 Redis。

但建议预留。

# 十、文件存储

V1.0 默认使用本地存储：

```text
storage/uploads/
```

目录：

```text
storage/uploads/user/YYYY/MM/DD/

storage/uploads/ai/YYYY/MM/DD/

storage/uploads/hairstyle/YYYY/MM/DD/

storage/uploads/hair_color/YYYY/MM/DD/

storage/uploads/article/YYYY/MM/DD/
```

---

# 十一、Storage 软链接

需要执行：

```bash
php artisan storage:link
```

确保前台可以访问公开资源。

---

# 十二、未来对象存储

后续可迁移到：

```text
阿里云 OSS

腾讯云 COS

Cloudflare R2

七牛云
```

业务代码应通过 MediaService 获取 URL，避免直接写死本地路径。

---

# 十三、AI 服务连接

HairHub 通过 API 调用 HairFastGAN 服务器。

配置项：

```text
ai.hairfastgan.api_url

ai.hairfastgan.timeout

ai.hairfastgan.enabled
```

部署要求：

```text
Web服务器可以访问AI服务器API

AI服务器接口需要鉴权

AI服务器需要超时保护

AI服务器失败要返回明确错误
```

---

# 十四、AI 调用安全

AI API 不应直接暴露给公网用户。

推荐：

```text
HairHub Web服务器

↓

内网或受限IP访问

↓

HairFastGAN API服务器
```

如果 AI 服务器必须公网访问，应配置：

```text
API Token

IP白名单

Nginx访问限制

请求频率限制
```

---

# 十五、队列与异步任务

V1.0 可先同步调用 AI API。

如果 AI 生成时间较长，建议使用队列。

队列适合处理：

```text
AI生成任务

图片压缩

公众号同步

媒体清理

Sitemap生成
```

---

# 十六、Supervisor

如果使用队列，需要 Supervisor 管理：

```text
php artisan queue:work
```

确保队列进程异常后自动重启。

---

# 十七、定时任务

服务器 Crontab 添加：

```bash
* * * * * php /path/to/hairhub/artisan schedule:run >> /dev/null 2>&1
```

用于：

```text
清理过期用户上传图片

生成 sitemap

同步任务检查

日志清理
```

---

# 十八、HTTPS

生产环境必须启用 HTTPS。

原因：

```text

微信浏览器访问

小程序接口调用

SEO信任

浏览器安全限制
```

# 十九、日志

Laravel 日志：

```text
storage/logs/laravel.log
```

建议区分：

```text
普通业务日志

AI调用日志

微信接口日志

上传错误日志
```

避免日志中记录：

```text
AppSecret

AccessToken

用户敏感图片完整地址

API密钥
```

# 二十七、部署架构总结

HairHub V1.0 部署采用：

```text
单 Web 应用服务器

+

独立 AI GPU 服务器

+

MySQL

+

本地 Storage

+

可选 Redis
```

整体目标：

> 先保证系统稳定上线，再根据真实流量逐步扩展。

V1.0 不做复杂分布式部署，避免增加个人开发和运维成本。
