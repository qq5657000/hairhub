# HairHub V1.0 模块设计

> Version: 1.0.0  
> Last Update: 2026-07-08

---

# 一、模块设计目标

HairHub V1.0 采用业务模块化设计。

模块划分遵循：

- 高内聚
- 低耦合
- 单一职责
- 可持续扩展

每个模块拥有明确业务边界。

模块之间通过：

- Service
- API
- 数据关联

进行协作。

---

# 二、系统模块总览

HairHub V1.0 包含以下核心模块：

```
HairHub

├── AI工具模块

├── 发型中心模块

├── 发色中心模块

├── 内容中心模块

├── Media资源模块

├── SEO模块

├── CMS管理模块

└── System系统模块
```

---

# 三、AI工具模块

## 3.1 模块目标

AI工具模块是 HairHub 的用户入口。

通过 AI 换发型、AI 换发色功能，降低用户尝试新发型的成本。

目标：

> 让用户在真正剪发、染发之前，提前看到效果。

---

## 3.2 V1功能范围

包含：

### AI换发型

功能：

- 上传用户照片
- 选择目标发型
- 调用AI模型
- 生成效果图


### AI换发色

功能：

- 上传用户照片
- 选择目标发色
- 调用AI模型
- 生成染发效果

---

## 3.3 核心数据

主要数据：

```
AI任务

用户上传图片

目标发型

目标发色

AI模型

生成结果

任务状态
```

---

## 3.4 AI架构关系

```
AI模块

↓

AiService

↓

AI Provider

↓

HairFastGAN API
```

未来支持：

- OpenAI
- Flux
- ComfyUI
- 其它模型

---

## 3.5 V1不实现

暂不包含：

- 用户AI历史
- AI积分
- 会员权益
- AI次数限制
- AI推荐算法

# 十四、模块设计总结

HairHub V1.0 的核心结构：

```
AI工具

负责获客


发型/发色数据库

负责沉淀资产


内容中心

负责SEO增长


微信生态

负责商业转化
```

整体目标：

> 构建一个以 AI 工具吸引用户，以发型内容形成长期资产，以 SEO 获取自然流量，以微信生态实现商业闭环的平台。
